# Phase 2: 全屏阅读器 UI、视口窗口与章节选择页 指导文档（方案 B：提词器同步）

## 1. 本期开发目标

构建手机端全屏小说阅读器 UI，实现：

- 手机端舒适阅读排版（按每行 N 字规整，仅手机视觉舒适性）；
- **阅读位置高亮视口**：高亮当前阅读位置，映射眼镜提词的 `highLightOffset` 字节偏移；
- 滚动滑出 / 音量键 / 点击分区 / 进度条统一驱动**翻页（seek 字节偏移）**；
- 中间区域点击唤出的 Overlay 菜单（章节内进度条、上一章/下一章、章节选择目录页）。

> 方案 B 语义（重要）：不再要求「手机一行 == 眼镜一行」。手机端 N 字/行决定排版、M 决定**视口每次移动的行数（翻页步长）**；眼镜自行排版并按字节偏移高亮。视口高亮框覆盖「以当前字节位置为中心的手机端 M 行」，属于**近似对应**（N/M 的眼镜端对齐后续通过实机测试校准）。

## 3. 详细设计与交互规范

### 3.1 界面架构与组件划分 (`ReaderScreen.kt`)

`ReaderScreen.kt` 包含三个主要 UI 模块：

1. **书架主视图 (BookLibraryScreen)**：展示已导入图书卡片网格/列表，顶部提供「导入 TXT」按钮。
2. **全屏小说阅读器 (FullScreenReaderScreen)**：沉浸式阅读界面，渲染规整行文本、绘制当前阅读位置高亮框，捕获手势与按键。
3. **章节选择目录页 (ChapterSelectionBottomSheet)**：弹出式章节目录列表，高亮当前章并支持点击跳转。

> 遵循工程「单文件 ~600 行、按职责拆分」约定，若本文件超限，将书架与章节选择拆出为 `ReaderLibraryScreen.kt` / `ReaderChapterSheet.kt`。

### 3.2 全屏阅读器与阅读位置视口绘制 (`FullScreenReaderScreen`)

#### 1) 手机阅读排版

- 根据每行设定格数 N（默认 18），手机端用 `formatLines` 结果渲染（每行 N 个显示格），通过字号与内边距保证阅读舒适。
- 该排版**仅服务于手机端视觉**，与眼镜端逐行对齐不再是目标。

#### 2) 阅读位置高亮框 (ViewportOverlay)

- 高亮框覆盖**当前阅读位置**所在的手机端行范围：以 `byteOffset` 换算出的格偏移为中心，覆盖其前后 M 行（默认 5 行）。
- 高亮框上方印有指示标签「眼镜同步视口」。
- 因眼镜自行排版，高亮框代表「眼镜当前阅读到的位置」，与眼镜实际可见行数是**近似关系**，不是逐字逐行映射。

#### 3) 翻页与边缘检测伪代码

```
当 手机阅读界面发生滚动手势 / 视口接近边缘:
    计算 当前高亮位置在屏幕中的像素位置
    若 视口上边缘越过顶部安全边界:
        翻页(向前 = -M×N 格)
    否则若 视口下边缘越过底部安全边界:
        翻页(向后 = +M×N 格)

函数 翻页(步长格数):
    新字节偏移 = cellOffsetToByte(当前格偏移 + 步长格数)
    调用 UI 层回传的 seek(新字节偏移)   // Phase 3 负责推送到眼镜
    若 新字节偏移 < 0 且存在上一章:
        切换到上一章，字节偏移设为上一章末尾
    若 新字节偏移 >= 全书字节数 且存在下一章:
        切换到下一章，字节偏移设为下一章 byteStart
    触发界面平滑滚动至新的阅读位置
```

### 3.3 音量按键接管与手势拦截

全屏阅读界面拦截系统音量键事件（Compose 可聚焦 `onKeyEvent`，拦截后 `return true` 抑制系统音量面板）：

```
当 捕获按键按下:
    若 音量下键:
        翻页(向后 = +M×N 格)   // seek 到下一个视口
    若 音量上键:
        翻页(向前 = -M×N 格)   // seek 到上一个视口
    越界时提示 "已到本书开头/末尾"
```

### 3.4 区域点击与 Overlay 菜单

将全屏阅读界面按 Y 轴分为 3 个逻辑块：

- **顶部 1/3 点击**：翻页向前（`seek(当前字节 - 一步)`）。
- **底部 1/3 点击**：翻页向后（`seek(当前字节 + 一步)`）。
- **中间 1/3 点击**：切换 Overlay 控制菜单显隐。

#### Overlay 菜单构成：

- **顶部菜单 (TopBar)**：返回书架、小说名、当前章节名、眼镜同步状态指示灯。
- **底部菜单 (BottomBar)**：
  - **章节内进度条 (Slider)**：展示 `当前字节偏移 / 本章字节数`，拖动时即时 `seek`。
  - **快捷操作按钮**：上一章、目录 📋、下一章、设置 ⚙️（调 N / M / 眼镜 `size` / `width` / `leading`）。

### 3.5 章节选择页 (ChapterSelectionBottomSheet)

- 列表展示当前小说所有章节标题，高亮当前章并显示 `[当前]`。
- 点击任意章节项：
  1. 切换当前章节；
  2. 重置阅读位置为 `chapter.byteStart`；
  3. 关闭目录页，恢复全屏阅读（Phase 3 会 `seek` 到该字节偏移，无需重启提词会话）。

## 4. Step-by-Step 实施步骤

1. **步骤 1**：创建 `BookLibraryScreen`（书架卡片 + 文件导入入口）。
2. **步骤 2**：创建 `FullScreenReaderScreen`，用 `formatLines` 结果做手机端舒适排版。
3. **步骤 3**：实现 `ViewportOverlay` 阅读位置高亮框与滚动边缘触发的翻页算法。
4. **步骤 4**：绑定按键监听，音量上/下键驱动翻页（seek 字节偏移）。
5. **步骤 5**：实现区域点击划分与 Overlay 菜单（TopBar、BottomBar 进度条与上/下一章、设置）。
6. **步骤 6**：实现章节选择目录弹窗与快捷跳转。
